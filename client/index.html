Privacy Policy

1. Commitment to User Privacy

Agent Orchestration Platform is built with strict privacy-by-design principles. We do not sell, monetize, or track your personal information or prompt history.

2. Offline Privacy Mode & Local Execution

When Privacy Mode is enabled, all cloud API outbound calls are blocked. All prompt processing, feature extraction, and multi-agent workflows execute strictly on your local hardware via Ollama and local storage.

3. Automatic PII Redaction

All prompts routed through the Cost Autopilot Gateway pass through a local regex and entity sanitizer to redact sensitive identifiers (emails, phone numbers, API tokens) prior to any external model dispatch.

4. Data Retention & Caching

Exact-match cache entries, Prompt Vault records, and evidence ledgers are stored in local SQLite records on your machine. No third-party tracking pixels or telemetry scripts are used.
